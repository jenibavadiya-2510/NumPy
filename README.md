# NumPy Practice Programs 🐍

## 📌 About This Project
This repository contains my Python NumPy practice programs. I created this project to learn and practice NumPy concepts that are useful for Data Analysis.

## 🎯 Objectives
- Learn NumPy fundamentals.
- Understand array creation and manipulation.
- Perform mathematical and statistical operations.
- Practice numerical data processing using Python.

## 📚 Topics Covered
- NumPy Introduction
- Array Creation
- Array Indexing and Slicing
- Array Attributes
- Array Reshaping
- Mathematical Operations
- Statistical Functions
- Working with Multidimensional Arrays

## 🛠️ Technologies Used
- Python
- NumPy
- Visual Studio Code

## ⚙️ Installation

Install NumPy using pip:

```bash
pip install numpy
```

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open a Python file.
4. Run the following command in the terminal:

```bash
python filename.py
```

Replace `filename.py` with the name of your Python file.

## 💡 Example

```python
import numpy as np

arr = np.array([10, 20, 30, 40, 50])

print("Array:", arr)
print("Mean:", np.mean(arr))
print("Maximum:", np.max(arr))
print("Minimum:", np.min(arr))
```
